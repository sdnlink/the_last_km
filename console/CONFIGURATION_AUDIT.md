# Web 与 CLI 配置接线核对

更新日期：2026-11-08。

Web 新建任务现已提供：需求文本、项目目录、worker/reviewer 及模型、固定模块 JSON（含 acceptance、depends_on、checks）、验收模式及命令、worker/reviewer 隔离与保护路径、单轮/空闲/验收超时、周期审核、累计时间/调用/轮次预算、保留轮数以及运行目录/Git 历史/本机模型会话容量限制。配置经服务端校验后进入真实 CLI 参数。

新任务默认 strict reviewer；Paseo daemon 不支持 strict，必须换用原生 reviewer 或明确选择 provider 边界。Paseo reviewer 仅支持 Claude plan。strict worker 的运行目录必须在目标项目外（控制台可用外部 --data-dir）。启动前实际探测严格审核挂载能力，不以命令存在代替可用。

Web 默认要求至少一条独立验收命令；可明确选择“仅双方审核”，此模式不能证明功能经过测试。兼容旧 API：未提供 verification_mode 的调用沿用 review_only；新页面始终明确发送选择。

恢复窗口允许追加运行时间和 worker/reviewer 调用轮次，保留已消耗量与原验收条件。未增加已耗尽预算时拒绝恢复。新上限和原参数保存于 resume_argv，控制台重启后沿用。历史任务不会被静默改成 strict，也不会因升级自动增加预算。

默认保留 50 轮，运行目录上限 64 MiB、共享 Git 对象及项目审计历史 512 MiB、已知本机模型会话目录合计 4 GiB；页面中均可修改，0 表示关闭对应限制。容量是定期采样的停止条件，不是文件系统硬配额；不会删除历史。共享目录包含其他任务及既有会话，不能视为本任务独占用量。Paseo daemon 和未登记的第三方存储仍需部署层磁盘配额。

仍由 CLI 或部署配置的项目包括：权限模式、extra arguments、自定义 worker、重试/连续失败/停滞策略、每进程内存和单文件限制、单轮原始输出限制、guard 重启细节，以及 systemd、执行器登录和 API 配置。Web 已提供独立 Paseo reviewer backend 和文字完成标准（进入 --accept）。Web 固定启用 guard 和 required Git 留痕。具体能力边界不能推断为所有 CLI 参数均有页面入口。

回归覆盖：父子工作区互斥、同一 Git 工作树子目录互斥、独立 linked worktree 可运行；表单参数进入 CLI；固定模块依赖拒绝；无命令不能选择命令验收；累计预算追加；共享存储超限在调用前停止；三方子进程自检和文档历史证据分层。

质量策略已新增 JSON 输入并接入 CLI 的 `--quality-policy`：固定需求追溯、原测试及命令脚本保护、验证进展停止门槛、时间/文件数审核、重复阻塞停止、受限审核工具及后端报告用量预算。模块接受 `files` 范围。新表单预填策略，旧 API 未提供时保持兼容。恢复读取检查点中的策略，拒绝替换原规则。具体字段与后端支持见 [质量策略](../QUALITY_POLICY.md)。

2026-11-09：验收基础区域改为任务类型、文字完成标准、项目只读扫描与检查项选择。所选命令由服务端重建，文字标准通过 --accept 进入监督配置；高级手填命令兼容。环境预检不执行测试，启动前重新检查入口及环境。增加仅制定验收方案的明确任务范围，实际检查快照与日志在详情展示。见 [引导式验收](../ACCEPTANCE_GUIDE.md)。

新建任务默认 workflow=review-first：reviewer 先完善需求，watcher 固化后交 worker。完成候选或外部阻塞立即送审；其余进展默认累计 5 轮审核，质量策略检查点也可提前触发。review_every=1 表示每轮正常结果后审核，0 关闭周期审核但保留完成候选、阻塞和质量策略审核。双方确认及实际验收通过后，业务代码提交到启动时的本地业务分支，审计结论保存在独立隐藏引用。旧任务恢复按检查点保留 legacy，不静默升级。CLI 可显式选择 --workflow；Web API 保留显式 legacy 兼容入口。需求完善不修改原始需求、验收命令、固定模块或质量策略。

创建校验区分省略项目目录（旧 API 使用控制台默认项目）和显式空白目录（拒绝并提示完整路径）。角色及后端先去除首尾空格，再按保存值校验隔离组合；strict worker 在保存前要求运行目录位于项目外。非法输入不会留下待启动记录。单轮/无输出超时 0 关闭对应超时，验收超时须大于 0；保留轮数 0 表示不按轮数裁剪，不会解除容量预算。
