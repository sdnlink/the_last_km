完成标准与检查方案

扫描只读项目配置，不执行测试、不安装依赖。选择检查后，watcher 会在验收时实际执行。

独立语义审核始终保留。未选择的功能、数据库、HTTP、端到端和性能检查不能推定通过。

高级：解释器与自定义命令 自定义命令会在项目目录执行，其依赖和副作用无法由入口扫描完整确认。
高级执行配置可选
时长、调用和执行轮次上限设为 0 表示不限。暂停在当前轮次结束后生效。
单轮和无输出超时设为 0 表示关闭该超时；单条验收超时必须大于 0。以上时间均以秒计。
