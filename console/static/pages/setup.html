首次安装指引

  1. 检查运行环境
    Git
    Bubblewrap
    Node.js / npm
  2. 准备执行器和审查器

    在下方启用所需 Agent，点击「安装选中项」补装缺失的 CLI。审查器请选择带 Reviewer 标识的 Agent。

  3. 完成认证并进入控制台

    打开 Agent 配置，沿用终端登录或填写受支持的 API Key，然后点击「保存并进入控制台」。

API Key 仅保存在当前用户可读的本地配置中，保存后不回显。CLI 检测不代表账户已登录或模型调用权限可用。
